# Learner Profile

## Initial Idea
웹 애플리케이션 개발 및 유지보수에 사용하는 외부 API의 연동 상태, 접근 권한, 장애 대응 능력을 자동으로 분석하고 검증하는 도구. 사용자 본인과 다른 개발자가 대상이다. API 문제가 발생했을 때 원인을 파악하는 데 도움이 되기를 기대한다. 초기 아이디어이며 승인된 구현 범위는 아니다.

## Demonstrated Technical and Agent Experience
AI 코딩 에이전트 사용 경험이 많다고 보고했다: “AI 에이전트는 꽤 많이 사용했고”. 코딩 경력, 사용 언어 및 도구는 아직 확인되지 않았다. 실제 구현 능력을 관찰한 것은 아니다.

## Planning-Workflow Experience
구현 계획을 먼저 작성하는 경험은 거의 없다: “구현 계획 작성은 거의 안 해봤어”. 계획 작성 과정은 단계별 안내가 필요하다.

## Desired Learning Outcome
“구현 계획을 작성하는 방법”.

## Learning Moments
아직 기록된 실습 없음.

## Interests, Inspirations, and Goals
소프트웨어 개발 및 개발자를 위한 도구에 관심이 있다. 구체적인 API 장애를 직접 경험한 것은 아니며, 웹 서비스의 API 문제 원인 파악에 유용할 것이라는 기대에서 출발했다.

## Vocabulary and Concepts Likely to Need Explanation
구현 계획을 작성하는 과정과 판단 기준을 설명할 필요가 있다. 다른 기술 용어에 대한 익숙함은 확인되지 않았다.

## Collaboration and Communication Preferences
한국어로 진행하기를 명시적으로 요청했다. 단계별 안내와 한 번에 한 질문을 적용하며, 계획 검토는 HTML 보조 페이지를 함께 제공한다.

## Areas Where the Learner Wants Ownership
not established

## Likely Support Needs
아이디어를 작은 검증 가능한 범위로 좁히고, 요구사항을 구현 단계와 검증 기준으로 연결하는 과정 안내. 구체적인 기술 및 환경 지원 필요 여부는 미확인.

## Review Format
html

## Notes and Open Questions
초기 도구는 개발 및 유지보수 상황 모두를 염두에 두고 있다. 첫 시제품의 사용 상황, 입력 방식, 검사 대상 API, 장애 대응 검증의 의미와 범위는 scope 및 후속 계획 단계에서 정한다. 실제 장애 경험을 전제로 하지 않는다.
