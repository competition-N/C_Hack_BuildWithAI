# Spacing and layout tokens

4px 단위다. 섹션 사이는 섹션 안보다 넓게 둔다.

| Token | Value | Use |
|---|---|---|
| `--space-1` | 4px | 글자와 표시 사이 |
| `--space-2` | 8px | 버튼 사이, 목록 항목 안 |
| `--space-3` | 12px | 입력칸 안쪽, 표 칸 안쪽 |
| `--space-4` | 16px | 섹션 안 요소 사이 |
| `--space-5` | 24px | 섹션 안쪽 여백, 섹션 사이 |
| `--space-6` | 32px | 화면 제목 아래, 본문 좌우 여백 |
| `--space-7` | 48px | 화면 위아래 여백 |

| Token | Value | Use |
|---|---|---|
| `--radius-1` | 4px | 표시(배지) |
| `--radius-2` | 6px | 버튼, 입력칸 |
| `--radius-3` | 8px | 섹션 |
| `--side-width` | 232px | 왼쪽 메뉴 너비 |
| `--content-max` | 1120px | 본문 최대 너비 |

## Breakpoints

- **좁음** (~719px): 왼쪽 메뉴가 화면 위 가로 메뉴가 된다. 모든 내용이 한 열이다. 표는 가로로 스크롤된다.
- **중간** (720~1023px): 왼쪽 메뉴는 200px. 프로젝트 관리와 문서는 한 열이다.
- **넓음** (1024px~): 왼쪽 메뉴 232px. 프로젝트 관리는 목록과 상세 두 열, 문서는 두 열이다.
